
Quick ways to add it
- On the page you opened (https://github.com/MayorAk/utilfive/new/main?filename=README.md): paste the content and click "Commit new file".
- Or via git:
  1. git checkout -b add-readme
  2. Save the file as README.md
  3. git add README.md && git commit -m "Add README"
  4. git push --set-upstream origin add-readme and open a PR
